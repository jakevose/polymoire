Polymoire

A generative visualizer that drifts between looks and moves to whatever your computer is playing. Spotify, a browser tab, a DAW: anything you can hear.

Download {{version}} Source on GitHub

Free for Windows, macOS and Linux. Vibe coded: read that section before you install it.

Listens to your computer

It analyzes the sound your computer is already playing: kicks, snares, hats, tempo, loudness, mood. Nothing is recorded, saved or sent anywhere.

Never the same twice

Thirteen traits (palette, field, symmetry, texture, effect, warp and more) shift one or two at a time on the beat, so the picture keeps changing without ever cutting. When the music stops, it settles into a slow drift.

Moves with the drums

Each kick pushes the patterns forward and they coast until the next. Quiet passages move gently; drops hit harder.

Easy on the eyes

No flashing: brightness changes are small and slow. Whole-view zooms and sways are rationed to every other beat, and Reduce motion turns them off.

Five looks from the demo beat

Each picture is a real frame from the app's own shader, rendered while its built-in 120 bpm demo loop plays, just after a kick. The traits under each one are the settings that made it; in the app they drift on their own, or you can step and pin them.

Download

macOS

Open the .dmg and drag Polymoire to Applications. The app isn't signed with a paid Apple certificate, so the first launch is blocked: open System Settings → Privacy & Security, click Open Anyway next to Polymoire, then confirm. (On macOS 14 and older: right-click the app → Open.)

To hear what your Mac plays, Polymoire needs macOS 14.6 or later and asks for System Audio Recording permission once. Older versions still run the visuals and the demo beat.

Windows

Run the installer. It isn't signed with a paid certificate, so SmartScreen shows "Windows protected your PC": click More info → Run anyway. System audio works out of the box.

Linux

.deb: sudo apt install ./polymoire_*.deb. AppImage: chmod +x it and run it. Listens through the PulseAudio or PipeWire monitor of your default output (standard on desktop distros).

Older versions and release notes are on the releases page.

Vibe coded, honestly

Polymoire was made by describing what it should do to an AI and judging the results, not by writing the code by hand. Nearly all of it (the Rust, the shaders, the tests, the build scripts and this page) was written by Claude, Anthropic's AI model, working in Claude Code. One person steered: asked for features, watched and listened to the result, and said what felt wrong.

What that means for you:

  • Nobody has read every line. The code hasn't had a human code review or a security audit.
  • It's checked by machines, not people. {{tests}} automated tests run on Windows, macOS and Linux for every change. The comfort rules (no flashing, gentle camera) are enforced by tests, and the beat detection is tested against a synthetic track with known kicks.
  • It does a small number of things. It draws to a window and reads audio. It has no networking code, accounts, telemetry or update checks, and it saves nothing (apart from a diagnostic screenshot in a developer self-test mode that's off unless you switch it on with an environment variable). Every crate it depends on is listed below with a risk rating.
  • Treat it like the toy it is. If something breaks or looks off, open an issue.
